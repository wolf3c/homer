# 模型、费用与数据

本文说明当前实现和计划的区别。当前公开仓库仅包含文档，源码与正式安装包尚未发布。正式发布前仍需完成许可、接入、定价及发行验收；此处不提供已开放的充值、套餐登录或安装包入口。

## 客户端和模型费用

荷马计划免费提供本地客户端，官方按量模型服务作为可选项。模型服务费与客户端是否免费是两件事，不能把客户端免费理解为任务零费用。

| 方式 | 当前说明 |
| --- | --- |
| 用户自己的模型连接 | 需要自己有权使用的服务及执行环境；实际兼容性、鉴权和可用模型须验证，费用依照相应服务计算。 |
| 自己的 ChatGPT 套餐 | 属于计划中的接入方向；实现及对外接入资格仍待确认，不能承诺直接复用电脑上的登录或套餐。 |
| 官方按量模型服务 | 计划作为可选付费服务，公开价格、试用额度、支付和退款条件尚待确定，不把内部测试连接当作公开销售入口。 |

一次任务可能产生主 Agent、多个 Worker、工具调用、重试和后续修订等多次请求。实际费用受模型、输入输出、缓存、执行方式和服务规则影响。本页没有固定任务报价，也没有经过验证的全局费用硬上限承诺；开始真实任务前，先确认所选服务的费用、额度和可用控制。

“按量收费”不自动表示按采购成本原价转售。具体服务价格应在上线时单独说明，不在当前文档中承诺零差价或无限免费试用。

## 数据存放与发送

| 位置或接收方 | 可能包含的数据 |
| --- | --- |
| 本机 Homer 数据目录 | 运行 SQLite、对话和任务历史、待确认事项、附件引用、工作区材料及交付文件。具体位置取决于配置和入口。 |
| 本机 Codex Home／账户配置 | 原生会话、工具配置及认证信息；部分配置和认证以本机文件保存，不声称全部由系统钥匙串加密。 |
| 所选模型服务或模型网关 | 对话、任务指令、实际读取的材料、图片及工具结果等完成任务所需的输入。其保存方式以该服务规则为准。 |
| 账户网站和官方服务（使用时） | 登录授权、账户配置、余额或用量查询等所需的信息；真实模型请求也会经过所选服务。 |
| 已启用的工具、MCP、插件或第三方渠道 | 与获准操作相关的输入和结果；可能发生独立网络请求或本机执行，不等于只与模型服务通信。 |

因此，本机运行不等于完全离线或所有资料永不出机。使用客户资料前应先取得相应授权；首轮体验优先选择公开或虚构材料。具体文件和工具可访问范围以实际配置及当次授权为准。

## 数据目录与删除

源码默认应用数据在 macOS 的 `~/Library/Application Support/Homer`，其他系统默认 `~/.local/share/Homer`；`appData`、`workspace`、`runtime`、Codex Home 等配置可改变位置。现有桌面入口默认使用 `~/Library/Application Support/Homer Desktop`，经明确采用的配置可能指向既有目录。不要只根据应用名称猜测实际数据位置。

删除应用程序或源码目录，不保证清除另处保存的历史、认证、文件、系统浏览器状态或远端模型记录。若要清除自己的本地数据，应先正常退出并确认后台执行结束，再核对实际配置的目录、备份和要删除的范围。本文不提供一键清除承诺，也不要求删除其他应用的数据。远端记录需按相应服务提供的规则处理。

## 本地接口与权限

桌面 API 使用每次启动生成的私有凭据，由主进程自动处理。开发浏览器入口继续免配对，仅适用于可信本机开发；不要把开发端口暴露给他人。两者都不替代操作系统权限、工具沙箱或用户对外部操作的批准。

安装或启用新工具前，核对它会访问的文件、账户、网络及可能费用。对于重要成果，核查材料来源和实际文件内容；已有任务完成状态不代替人的业务验收。

## 反馈时提供什么

可在 [GitHub Issues](https://github.com/wolf3c/homer/issues)提问或反馈。安装和使用问题可按[问题模板](../../.github/ISSUE_TEMPLATE/bug_report.yml)提供版本、系统、可公开的最小复现步骤、预期与实际表现、错误码；目前公开仓库仅含文档，尚无可安装版本。

不要上传密钥、登录文件、完整会话、提示词、工具参数或结果、客户材料、数据库及包含私人信息的截图。请用虚构输入描述复现步骤。尚未建立并验证专用私密报告渠道，不应把公开 Issue 当作私密收件箱。
