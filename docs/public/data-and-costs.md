# 软件免费，服务按需

[English](data-and-costs.en.md) | **简体中文**

荷马计划免费提供客户端，模型调用费用另计。当前[仓库](https://github.com/wolf3c/homer)已公开开发预览源码，正式安装包和公开服务价格尚未发布。

## 模型怎么用，由你选择

| 方式 | 费用与状态 |
| --- | --- |
| 荷马会员服务 | 可选的按量模型服务，按需购买额度；具体计价、试用、支付及退款规则以正式发布为准。“会员服务”不表示已推出订阅套餐。 |
| 我的 ChatGPT 套餐 | 计划通过 Codex 接入已有套餐，接入方式、使用资格和可用性仍待确认。 |

一次任务可能包含多个 AI 助手、重试和后续修订，实际消耗取决于模型与用量。没有固定任务报价或经过验证的全局费用硬上限；按量收费也不表示按模型采购成本原价转售。首页额度卡片属于展示示意，不作为当前销售承诺。

## 我的资料会发送到哪里？

对话历史、运行数据和成果文件会保存在配置指定的本机目录。执行任务时，对话、读取的资料及工具结果可能发送给所选模型或工具服务；使用荷马会员服务时，相关请求也会经过该服务。远端保存规则由相应服务说明。

本机运行仍可能产生网络请求。使用客户资料前应取得授权；首次体验优先使用公开或虚构材料。启用 Skill、MCP 或插件前，确认它可访问的文件、账户、网络及可能费用。

## 本地保存与删除

源码默认数据目录为 macOS 的 `~/Library/Application Support/Homer`，其他系统为 `~/.local/share/Homer`；桌面入口默认使用 `~/Library/Application Support/Homer Desktop`。实际位置取决于配置和已采用的资料目录，工作区、运行数据与 Codex Home 也可能另设。认证信息可能保存在本机文件中，不保证全部由系统钥匙串加密。

卸载应用不一定清除历史、认证或成果。清理前先正常退出，核对实际目录与备份范围；远端记录按相应服务规则处理。桌面自动认证和开发入口权限详见[运行指南](getting-started.md#本地-web-与桌面端)。
