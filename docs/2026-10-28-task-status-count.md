# 工作状态任务数量角标

顶栏沿原工作状态入口显示工作中的用户根任务数。复用原全量任务快照及面板工作中统计；同一根下多个 Worker、嵌套任务、版本和重试只计一次。排队、待用户处理不进入角标。执行完成仍按原成功 Worker 执行、待处理仍按请求计数，原三个筛选保持，排队数量另列说明。

入口为 60×44px，18px 图标与固定 22px 数字槽，胶囊高 18px、11px/600 等宽数字。0 不显示数字和背景，保留槽位；100 起可见 99+，可访问名称保留准确数量。读取失败、未加载、断线、过期或执行身份不明时不冒充已知 0；面板沿原上次记录提示。
