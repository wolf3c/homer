| 暖灰鼻吻 | `#B2A69E` | 178, 166, 158 | `#B4AAA3` |

深色主要用于五官；外部头形和吻部围合是主体灰，没有独立的深色描边。下缘代表值与主体略有差异来自图像本身的明暗，不另定义一个必须维护的品牌色。鼻吻以暖灰为主，灰粉局限在内耳，不据此给界面大面积铺粉。

原 PNG 外部透明，**没有可采样的白底或暖灰底**。浅底参考来自现有界面规范/本 worktree 样式，列在下一节，不能冒称为 Logo 原图底色。

### 取色方法与复算

在原始 1254px 图上，坐标原点为左上角，区域为左/上包含、右/下不包含的矩形：

| 区域 | 采样框 `[left, top, right, bottom]` | 裁尾后像素数 |
| --- | --- | --- |
| 主体 | `[520,300,730,400]` | 17916 |
| 鼻吻 | `[525,650,725,950]` | 49073 |
| 内耳 | `[285,215,335,265]`、`[920,215,970,265]` | 4121 |
| 眼鼻 | `[415,430,445,460]`、`[795,690,835,730]` | 2262 |
| 下缘轮廓带 | `[550,1120,700,1128]` | 1002 |

1. 使用远离透明轮廓、抗锯齿边沿与跨色边界的内部区域。只保留 alpha ≥253；实体区域原生多为 254，若只取 255 会漏掉主体。低透明度边缘像素、透明区隐藏 RGB 不参与。
2. 按区域内相对亮度的第 10/90 百分位界限裁掉极暗和极亮像素，包含并列值，以减弱局部阴影、高光影响；不声称全部生成明暗都能自动分离。
3. 求裁尾后 RGB 各通道中位数，选距该中位数最近的**实际保留像素 RGB**；同距优先频数高者，再按 RGB 排序。不是只凭一个吸管点或印象选色。JSON 保留代表像素坐标、各通道范围及方法。
4. RGB 为原始未合成值。PNG 无 ICC/sRGB/gamma 元数据，本次按 sRGB 分析，未做显示器校准；真实显示还受原生 alpha、背景与色彩管理影响。没有把它修改成完全不透明纯色图。

从仓库根复算并与 JSON 比较：

```sh
python3 assets/branding/source/homer-01n-river-stone/analyze-river-stone-palette.py
```

脚本只向标准输出写 JSON，先验证选定 PNG 的 SHA；如未来换图，会报错，须重新审阅采样区域和选择依据，不悄悄覆盖这份记录。

### 候选组合的数学对比度

按 sRGB 转线性亮度：`c = channel / 255`；`c ≤ 0.04045` 时 `linear = c / 12.92`，否则 `linear = ((c + 0.055) / 1.055)^2.4`。`L = 0.2126R + 0.7152G + 0.0722B`，对比度为 `(L较亮 + 0.05) / (L较暗 + 0.05)`。

| 前景 / 用途 | 白底 `#FFFFFF` | 暖灰底 `#F6F5F2` | 数学结果及限制 |
| --- | --- | --- | --- |
| 正文 `#292825` | 14.742:1 | 13.522:1 | 均超过普通文字 4.5:1 |
| 次级文字 `#67645F` | 5.891:1 | 5.403:1 | 均超过普通文字 4.5:1 |
| 品牌深灰候选 `#69635E` | 5.920:1 | 5.430:1 | 均超过普通文字 4.5:1 |
| 主体灰/边界候选 `#837C76` | 4.110:1 | 3.770:1 | 可供必要非文本边界的 3:1 数学候选；**不足普通正文 4.5:1** |
| 装饰线 `#DEDBD5` | 1.382:1 | 1.267:1 | 不足 3:1，不作必要控件轮廓或唯一状态线索 |

另一个候选：白字 `#FFFFFF` 放在品牌深灰 `#69635E` 实心按钮底上为 **5.920:1**。若未来使用，还需验证 hover、pressed、disabled、焦点与相邻背景，不能只验默认态。

普通文字 4.5:1、大文字 3:1 的说明见 [W3C SC 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)；识别必要控件/图形对相邻颜色的 3:1 要求见 [W3C SC 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)。判断使用未四舍五入的计算值，表格只保留三位小数。

这些是**不透明、纯色、指定前景/背景组合的数学结果**，不代表实际 UI 已验收或完整 WCAG 合规；不涵盖透明度、渐变、字号、字重、抗锯齿、焦点面积和其他邻接色。Logo 的天然半透明 PNG 不能直接当成这些不透明文字/控件 token。

## 适用、限制与以后如何参考

- 适合：保持 01N 原图及比例作品牌方向参考；在后续获授权的界面工作中，小范围比较品牌强调、图标和中性表面，再按组件职责选语义色。
- 保留既有红色停止/错误、微信绿色及其他状态含义、焦点可见性。不能把所有状态统一染成灰褐，也不能只靠颜色传达状态。
- 明暗背景：前一轮自然体色评审已在白、暖灰及深底 `#20262D` 样张中看过。中灰主体在该深底上较前轮 01A 更分明；不推导为所有暗色主题均可用，也不在本页另建深色主题 token。
- 小尺寸：16px 主要保留双耳与宽吻，眼睛和微笑仍小；24px 眼鼻更可辨，32/64px 较完整。边缘仍有少量生成杂色和质感，选定方向不等于完成矢量母版或最终 favicon。未来应专门整理母版及小尺寸，不以本轮归档代替生产验证。
- 不适用：原样复制河马各部位色到正文/状态色、批量重染界面、自动换 Logo/favicon、声称色彩心理学保证可靠性、声称商标可注册或已完成生产集成。
- 未来修改先指明组件、背景和目的；按本页归档取色与语义 token 分工提出局部方案，算具体组合，再实际查看浅深背景、交互状态和小尺寸。本页及 JSON 是维护参考，不是应用自动读取的配置。

自然参考来自 [丹佛动物园](https://denverzoo.org/animals/river-hippopotamus/) 的灰至板岩褐/面部局部粉色介绍及近照，以及 [比勒陀利亚国家动物园](https://www.pretoriazoo.org/animals/hippopotamus/) 的紫灰/板岩与眼耳周褐粉描述。光照、湿润反光、泥土和相机白平衡影响照片观感；鼻吻浅化及色彩分区是品牌艺术概括，没有把官方照片作为成品背景或精准生物色卡。
