# 网页批注随附截图方案

2026-11-25，已在独立源码候选实施并通过独立代码复核。本文覆盖桌面 Preview 的网页元素批注，包括使用同一原生批注运行时的本地和附件 HTML。

## 已确认的方案方向

每条新网页批注首次保存时自动截取可见视口，随备注进入原 Composer 草稿。截图保留网页原画面，界面通过覆盖层显示框和编号。能确认画面完全相同的批注共用一个附件版本。模型先收到完整批注及按图分组的坐标，通过现有附件授权按需读图。首版统一按需读图，单图直送留待独立评估。

“把按钮改成『保存』”通常只需文字和选择器。窄视口遮挡、裁切、画布状态或登录后只出现一次的界面需要当时的画面。自动截图覆盖网页可见视口。若反馈对象是 Homer 自己的备注弹窗，可用已有桌面截图记录完整现象。 [过往裁切复现](preview-architecture.md#网页批注弹窗视口避让) · [桌面截图批注](../desktop-screenshot-annotation.md)

## Homer 已有的路径

网页批注把元素文字、选择器、批注时的位置和备注写入草稿。发送时服务层验证来源，再把网页信息和备注整理成文字输入。已获准的 Agent 可另用 `preview_screenshot` 获取对应页此刻的可见视口 PNG。主会话已用现有媒体链提交用户附上的原图。已有图片批注按附件版本和原图尺寸发送区域列表，模型读取原图；框和编号用于界面展示。网页批注复用这套表达和附件链。 [编号图研究结论](../image-region-annotation-design.md#8-旧方案撤回与后续实施边界) [当前网页保存](../../ui/browser-preview.tsx#L57) · [结构化文字](../../src/preview-reference.ts#L141) · [原生截图](../../packaging/electron/preview-pages.mjs#L359) · [主会话图片](../../src/service.ts#L1966)

## 保存、取图与归并

1. 用户照常点选、写备注并保存。批注模式下页面可以滚动，点击由选取逻辑接管。每条新批注自动尝试取一帧，仅修改已保存的备注时沿用原图。由可信用户输入触发保存，使用仍连接的原 DOM 节点重新取视口矩形，网页位置与截图像素都用这次取帧的状态换算。 [页内批注运行时](../../ui/browser-annotation.tsx)
2. 让备注框、悬停提示和批注标记暂时退出绘制，页面自己的遮挡、模态和样式照常显示。等待绘制更新后，由主进程对该原生网页视图取一帧。取帧前后核对页签、文档、草稿代次和用于换算的视口及目标位置。滚动、重排或导航使图和目标无法可靠对应时，保留文字并提示截图未附上。取帧前后比较原节点和几何。动态内容仍可能在检查之间重绘。延续文档、草稿代次和基准修订保护，在现有保存回执过期前一次写回备注和有效附件关联。回执过期或草稿变化时回收本次已准备的独有附件。 [原生视图与回执](../../packaging/electron/preview-pages.mjs) · [Composer 草稿接入](../../ui/browser-preview.tsx)
3. 在同一草稿内，以同一网页来源、同一文档、尺寸一致及保存图像的字节摘要完全相同为条件复用附件。每条批注仍保留独立 ID、原目标和对应区域。URL、滚动量和尺寸相同也可能对应不同画面。任何可见差异都保留独立帧，包括微小提示和遮挡。摘要不同的相似画面交给按需读取处理。
4. 草稿沿现有网页批注与图片附件入口查看、移除图片。移除单条批注时解除该条关联，最后一个引用解除后才移除随注附件。若从草稿移除一张共用图，相关批注均保留文字和网页位置。图上的框和编号通过界面覆盖层绘制，保存和发送使用无 Homer 标记的图。 [现有草稿与图片准备](../../ui/homer-app.tsx#L1065)

## 坐标、图片与模型输入

- 每条批注继续保存网页选择器和视口 CSS 像素矩形。取帧时先把矩形与可见视口求交，再按保存图宽高与捕获视口宽高的实际横纵比例映射。左上向下取整，右下向上取整，结果限制在图像边界。完全出视口或目标已失效时保留文字和已有定位，省略图上关联。
- 在现有网页批注条目上拟增加可选截图关联，保存 `assetId/revision`、实际图片宽高和对应的 `region`。图像字节沿用现有媒体附件，复用其上传、版本和回收规则。接收时核对附件归属及版本、解码尺寸和矩形边界。没有截图关联的旧消息按原规则读取。 [引用协议与图片批注序列化](../../src/preview-reference.ts#L141) · [现有来源与附件校验](../../src/service.ts#L1450)
- 模型输入沿用现有图片批注格式，按图列出附件版本和基底尺寸，再列出 `number`、`id`、`region`、`comment`。保留网页来源及 `elementPath`。区域以原图左上为原点，单位为原图像素。一张图可以对应多条备注，编号表示文字条目的对应关系。
- 主会话和 Worker 用现有 `inspect_attachment(assetId, revision)` 按需读图，工具回传实际图片内容与 `modelView` 尺寸。工具图缩小时，原图区域可分别按实际宽、高比例换算到工具图。需要操作当前网页时沿原方式重新读页面并定位。从初始模型图片列表排除随注图，授权附件仍可按需读取。主会话、转交和 Worker 读取均在现有附件授权链复查原始网页来源。队列就绪及领取检查先排除失效的随注图，普通附件保持既有检查。队列编辑维持原引用绑定，批注及关联的修改在普通草稿完成。来源失权时排除其来源材料和随注图，保留用户备注及说明。 [主会话派发](../../src/service.ts#L1481) · [图片读图工具](../../src/service.ts#L641) · [工具图片尺寸](../../src/media-decode.ts#L50) · [Worker 附件授权](../../src/service.ts#L404)

拟议模型文字节选。前两条保存的画面完全相同，第三条发生在滚动之后。示例中的附件身份是示意值。

```text
来源：结算页 https://shop.example/checkout
画面 A：asset-00000000-0000-4000-8000-000000000001 @ revision 1
图片尺寸：1600 × 1200。region 为原图像素，原点在左上角。
[
  {"number":1,"id":"note-1","elementPath":"#shipping-address","region":{"x":1120,"y":360,"width":480,"height":88},"comment":"输入框右侧被裁掉"},
  {"number":2,"id":"note-2","elementPath":"#shipping-note","region":{"x":1120,"y":480,"width":360,"height":52},"comment":"说明文字应再短一点"}
]

画面 B：asset-00000000-0000-4000-8000-000000000002 @ revision 1
图片尺寸：1600 × 1200。region 为原图像素，原点在左上角。
[
  {"number":3,"id":"note-3","elementPath":"#place-order","region":{"x":1020,"y":1040,"width":360,"height":88},"comment":"底部条挡住了确认按钮"}
]
```

查看画面 A 一次即可核对第 1、2 条。若工具返回 `800 × 600` 的 A，第 1 条在工具图里的框为 `(560, 180, 240, 44)`，保存的数据仍以 `1600 × 1200` 为基准。单图直送若获采纳，可复用现有原生 `localImage` 输入，路径仅供引擎读取。本方案暂按授权读图验收。 [原生图片输入](../../src/engine.ts#L1153)

## 失败、隐私与历史

在用户首次保存每条新批注时自动采集该页可见视口。桌面、其他标签、浏览器工具栏与屏外内容在该采集范围之外。屏内其他字段可能有隐私数据，用户可先用区域截图缩小范围，也可在发送前移除。取帧后优先复用附件限制和现有图像处理，必要时在本地等比缩小并以实际输出尺寸换算。较长页面也只取当前视口。视觉用量受输入尺寸和模型影响，首版用合成样本测量 PNG 字节、处理时间与可读性，保留当前媒体限制，再据结果定下发尺寸。 [Homer 媒体限制](../../src/media-policy.ts) · [图片输入与尺寸成本](https://platform.claude.com/docs/en/build-with-claude/vision#resolution-and-token-cost)

取帧、图像准备或尺寸校验失败时，仍可保存当时有效的文字批注，并提示「截图未附上」。文档或草稿失效时沿现有保存回执保留输入，迟到的图不进入新草稿。当前线路无法读图时仍发送文字批注，并说明截图无法用于本次模型输入。队列派发阶段发现图已不可读时按文字降级并说明。避免因截图处理失败丢失用户备注或提交重复批注。

发送后的批注继续使用已评审的只读消息气泡展示来源、元素和完整备注。截图沿现有消息图片附件入口查看，并显示与对应批注的关联。历史重开使用原消息和固定附件版本。页面关闭、导航或原目标消失时，已获准的图仍代表保存时画面，页面定位继续用当前页面校验。已删除、失权或未同步的图使用既有不可用提示。桌面负责采集，配对端沿用已有附件传输与查看能力。支持该可选字段的客户端才提供截图关联编辑，兼容性验收覆盖旧端只读和旧草稿恢复。 [只读气泡与批注重开](preview-architecture.md#批注定位与重开方案2026-11-23)
