## Apple 芯片 Mac 候选包实测

构建来源为已提交的 main `f026ffb3063da99ac2680e308a05f0d19432d4d9`。[GitHub Actions 第 1 次构建](https://github.com/wolf3c/homer/actions/runs/44667507029/attempts/1)使用同一提交的干净检出。Mac arm64 包为 0.1.20 / build 308，大小 432,379,948 字节，SHA-256 为 `24aa2f0d55f2308f32fcf8ffa9abe0c2528f476b36a6aec918172e4cd50e72d2`。已核对包内版本、源码和生产服务地址；签名、公证票据与 Gatekeeper 检查通过。

在 macOS 27.2 上，从该 ZIP 启动原签名应用。隔离主对话使用本机合成模型协议保持一轮处理中。通过发送按钮实际发出消息后，核对了两个画面：

1. 最新消息下方显示 40 × 40 CSS 像素的小 Homer。连续截图中可以看到不同的动作帧。
2. 趁同一轮仍在处理，再排入一条测试消息，形成可见的队列标题。向上滚动让行内动画离开阅读区后，同一个图像元素缩至 26 × 26，位于“消息队列 · 1 条待发送”标题行内。

测试没有使用日常账号或付费模型。首次启动引导影响了前两次测试准备；隔离资料标记为已看过引导后完成上述实测。退出时出现“系统唤醒清理未确认”。选择“仍然退出”后，隔离进程退出，owner、runtime 和 gateway 锁均释放，数据库 lease 为 0。系统当时列出的 Homer 唤醒事件和电源保护也为 0。原生自动升级未经实机验证。
