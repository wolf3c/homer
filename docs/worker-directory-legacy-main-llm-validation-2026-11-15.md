## 前置自检失败与修正

首次带 `--paid` 的入口在读取认证、创建实模业务轮之前，停在本地隔离自检：探针夹具仅按“带工具目录的第一条请求”发放命令响应，原生后台请求可能先消费它，导致没有执行预期的本地文件读取。该次业务轮数为零，所有模型上游均为回环，未发起付费业务调用。

只修正验证夹具，按固定探针模型及完整用户消息匹配，并加入“相同消息但后台模型”和“相同模型但无用户消息”两个干扰请求。两次后续本地自检通过；真正的三例实模只执行一批，没有失败后重试。正式 Main、派工句、工具说明、扫描和业务接口在整个过程中保持同一份快照。执行脚本哈希及前置失败记录保留在 JSON，不用失败前的本地合成 token 冒充实模消耗。
