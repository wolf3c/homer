# 工作收尾清理

面向开发 Agent 的项目工作区收尾；Homer 运行时的实际事项归档沿既有 homer-archive-review 处理。以当前产品和后续迭代需要判断保留价值。完成任务后执行实际清理，再交付结果；没有产生临时资源时直接结束。

## 范围与保留依据

- 本任务生成的无用途临时资源已有用户长期清理授权，按下列检查直接回收。其他任务和历史目录只在当前清理授权覆盖时处理。
- 保留源码、未提交或未合入工作、当前运行的数据与配置、凭据与签名材料、未完成任务的必要上下文，以及仍待交付或审核的发行材料。
- 产品设计、实现和可重复的验证入口维护在 Git 中。验收结论放正常 docs，私密运营资料放 `.codex/private/`。过去的安装包、源码副本、测试数据库、浏览器 profile、日志和备份不因“历史证据”而无限保留。
- 只有当前失败排查、未完成交付或具体的下一轮迭代直接依赖原始产物时才保留，说明用途和删除条件。已经公开且可重新下载的包、已入 Git 的代码副本、重复解压依赖和失效回退包可以回收。
- 共享依赖及下载缓存按实际使用和重新获取成本判断。按任务归属清理，不能把仍使用中的项目依赖当作测试副本删除。

## 执行

1. 核对 Git 状态、worktree、活动任务、进程命令／cwd／打开文件，以及日常应用采用的数据路径。目录名、时间早或没有进程都不能单独证明无用途。
2. 列出具体清理路径及用途判断。检查符号链接和嵌套目录，保留被运行实例、未完成工作或维护入口引用的实际目标。克隆目录先检查未提交内容和提交是否已合入；Git worktree 沿 Git 管理入口处理。
3. 在授权范围内按已核对的精确路径删除。不得使用按文件年龄直接删除、通配符递归删除、Docker 全局 prune 或未经核对的批量清理。不要把垃圾移进另一个备份目录长期占用空间。
4. 共享目录存在未完工作时，只清理已确认归属本任务的子目录。保留必要的交付材料后，移除重复安装包、解压 App、构建 staging、模块缓存、合成数据和闲置测试进程；正常退出本任务进程，禁止终止日常实例或身份不明的进程。
5. 核对剩余文件、受保护路径和 Git 差异，复测磁盘可用空间。移除不再需要的清理工具副本、临时清单和检查输出，避免清理本身产生新的长期垃圾。

## 交付

简述实际释放空间和主要清理范围。保留项只列具体用途与条件，明确无法处理的资源；需要复验已删除产物时，使用 Git 中的源码与测试入口重建。无新增遗留时不重复扫描整仓库。
