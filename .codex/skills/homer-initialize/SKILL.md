# Homer 首次初始化

初始化只准备工作方法。Homer 自定义预装内容为本 Skill、`homer-tool-management` 和 `homer-feedback` 的完整目录；初始化不调用反馈接口、不发送测试报告。Playwright、CUA、办公库、浏览器二进制等具体工具及依赖不预装。Codex 原生已提供的工具和系统 Skill 保持原样，已有安装不删除。

1. 从当前原生发现结果找到 `homer-tool-management`，读取其入口，确认参考文件存在且可按需读取。使用 Homer 专属 HOME 中的实际路径，不硬编码开发机路径，不借用全局 Codex／Cindy 的工具或凭据。缺入口或参考时明确报告分发缺口，不宣称初始化完成，不自己重建安装流程。
2. 若用户已有实际任务，先处理该任务；当前已提供的适用工具直接用，不先重复盘点本地工具；只有出现明确缺口时，才由工具管理 Skill 主动寻找、安装、配置、验证并继续原任务。不扫描整个市场，不逐类检查浏览器、电脑或办公能力，不为“初始化完成”下载软件、创建账号或发起付费测试。
3. 没有实际任务且管理方法可读取时，简短说明“初始化完成；需要时会按任务检查并获取工具”，并指出已知的分发或执行通道阻塞。这里只表示工作方法就绪，不表示浏览器、电脑控制或所有工具已安装、连接、验收。

首次自动消息是一次普通用户请求，不是任意程序、登录、系统权限、费用和外发的统一批准。安装采用、更新、必要确认和失败处理均委托工具管理 Skill，复用现有普通任务、原生审批与同线程自动续接；不把本可自行完成的安装交给用户，也不替用户批准待答卡。

重复执行或中断后核对当前原生事实，不恢复用户禁用、卸载或拒绝的工具；不后台循环重试。用户说“继续初始化”时按普通消息处理，仍只检查方法就绪；有具体任务才补该任务所需工具。本 Skill 不读写业务数据库，不建立完成标记、安装事实库、调度器或能力进度系统。
